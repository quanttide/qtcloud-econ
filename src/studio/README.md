# qtcloud-econ Studio

量潮经济云客户端（Flutter）。

## 结构

```
src/studio/
├── pubspec.yaml            # 项目配置（qtcloud_econ_studio）
├── lib/main.dart           # 入口（量潮经济云壳）
├── analysis_options.yaml   # lint 配置
└── test/                   # 测试（待建）
```

## 运行

```bash
flutter pub get
flutter run
```

## 定位

双轴架构中的**领域轴**应用（quanttide-econ/apps/qtcloud-econ），与平台轴（quanttide-platform/apps/qtcloud-econ）共享同一仓库。内容围绕经济建模：招聘博弈、博弈论驱动的经济体系认知。
